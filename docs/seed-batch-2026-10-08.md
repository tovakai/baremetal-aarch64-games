### Inclusion rules

- Publisher-provided Linux ARM64 ZIPs on itch.io are listed as **upstream** and **standalone**. If no reliable version is displayed, the JSON version field says `unversioned (itch.io)` rather than guessing.
- Community-hosted *reimplementations* (Davenstein, DevilutionX) are marked **community**, even though the builds are upstream relative to their own engine projects.
- An ARM64 build is not evidence of Steam Frame bootability. Note VR game Not Enough Fuel VR's explicit non-test.
- The ledger intentionally **excludes** game launchers, emulators, Android-only APKs, macOS ARM64 builds, and source-only ARM64 build recipes.
- Package listings can change. On link rot or an updated release, update the exact JSON version and evidence URL rather than silently asserting compatibility.
